# Dobrov Academy — brand v0.1

Первое направление, 21 октября 2026. Пользователь предложил Dobrov Academy / Dobrow Academy и сообщил, что оба домена куплены. Для реализации выбрано **Dobrov Academy**: единое написание с DenisDobrov, без дополнительного варианта фамилии.

## Название и домены

- Название: **Dobrov Academy**. В логотипе: `dobrov.` + `ACADEMY`.
- Основной планируемый домен: **dobrov.org**.
- Дополнительный: **dobrow.org**, позднее redirect на основной.
- Vercel project slug: `dobrov-academy`. GitHub repo пока остаётся `DenisDobrov/Playground`.
- Домены ещё не подключены. Canonical URL и redirects не включены до настройки DNS и TLS.

Academy здесь — научное медиа и пространство понимания. Курсы, аккредитация и образовательные сертификаты не подразумеваются.

## Обещание

**Ciencia con evidencia.** Новости AI, физики и космоса, которые дают источник, метод, контекст и ограничения. Дополнительная подпись: **Fuentes. Contexto. Perspectiva.**

Тон: спокойный, любознательный, ясный. Не преувеличивать научные результаты и не обещать того, чего нет в исследовании. Название бренда остаётся английским; редакционные тексты — нейтральный испанский.

## Визуальная система

| Роль | Цвет | Назначение |
|---|---|---|
| Ink | `#172B46` | Основной текст и знак |
| Evidence blue | `#315BDA` | Акценты, ссылки, действия |
| Paper | `#F7F5EF` | Тёплый фон страниц |
| Mist | `#E9EDF5` | Вторичные блоки |
| Slate | `#596C82` | Вторичный текст |
| Signal | `#7195FF` | Светлый синий на тёмном фоне |

Логотип: геометрическая D с горизонтальной осью и точкой — направление исследования от вопроса к наблюдению. Квадратный знак работает в favicon, аватаре и видеозаставке. Он не изображает академическую степень или университетскую печать.

Типографика: Arial/Helvetica для логотипа и интерфейса, Georgia для крупных редакционных заголовков. Это системные шрифты без внешних сетевых запросов; платные font licenses не нужны. В SVG wordmark текст зависит от системного шрифта, знак целиком задан paths; перед печатным тиражом текстовый логотип следует перевести в кривые.

## Файлы

- `apps/web/public/brand/mark.svg` — самостоятельный знак.
- `apps/web/public/brand/logo.svg` — горизонтальный логотип на прозрачном фоне.
- `apps/web/public/brand/brand-board.svg` — первая доска стиля и пример видеокарточки.
- `apps/web/app/icon.svg` — favicon.
- `apps/web/app/opengraph-image.tsx` — автоматически генерируемая PNG-карточка для ссылок.
- `apps/web/lib/brand.ts` — название, подписи, палитра и планируемые домены.

Свободное поле вокруг знака — не менее четверти его ширины. Не растягивать, не заменять букву D случайной иконкой и не использовать светло-синий для мелкого текста на белом. Научная маркировка и указание demo должны оставаться заметными независимо от брендинга.
