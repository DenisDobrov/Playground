Retain VIDEO-HLD/VIDEO-001 contracts, queue leases, ledger, private media, source lineage and separate article/video release gates.

1. **Licensed Spanish TTS.** Review provider/voice availability, license, current billing units/rates and a short pronunciation sample. Version the scientific lexicon. Bind text/script/voice hashes; reserve/start/settle, retain receipts and uncertain bills. Generate exact narration only after authorization. Measure real durations, align captions, review numbers/units/pronunciation and loudness/clipping. No implicit voice-cloning consent.
2. **Scientific scene templates.** Implement Remotion/React/SVG diagrams, attributed evidence callouts and dedicated caveat scenes using reviewed claims/located evidence. Check renderer licensing and rights for each asset. Label explanatory illustrations; do not present simulations as observations or invent quantitative data. Reuse unchanged clips only by validated input/output hashes.
3. **Optional presenter inserts.** Use only separately consented and approved owner media. Keep source files private, scope consent to exact assets/script/use, disclose synthesis and forbid unrelated/training reuse. Main scientific explanation/caveats remain complete with inserts disabled. Prefer the existing bounded still-motion fallback initially; external animation requires its own authorized budget/provider adapter and exact segment review.
4. **Assembly and QA.** Use measured audio to build the timeline; render scene clips, mux with FFmpeg, produce 1080p 16:9 H264/AAC MP4 and ES SRT. Detect missing media, checksum mismatch, caption drift, audio clipping, timing errors and omitted required caveats. Failed optional presenter work must not block a complete scientific cut. No automatic paid retries.
5. **Genuine human audiovisual acceptance.** Inspect scientific diagrams/meaning, narration/pronunciation, captions, rights/attribution, disclosure and exact final MP4. Bind source/brief/script/assets/audio/render revisions and approvals; changes invalidate relevant approvals and final assembly review. Deliver one understandable 6–8-minute pilot with measured costs and review effort. Local/private review delivery first; YouTube OAuth/private upload and public release require their own explicit authorization.

Acceptance evidence: exact source and text review IDs, asset/consent/license records, provider receipts/token/character/runtime costs, actual audio/video duration, SRT/timeline QA, cache/recovery test, MP4 checksum and final human approval. Offline fixtures never substitute for the real pilot or human review. HLD/MVP stays unchanged; no new cloud provider/configuration or production migration without approval.
